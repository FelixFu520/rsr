# Isaac 夹爪驱动调参

先读 [教程要点、公式与示例](references/tutorial-notes.md)，执行时填写 [本地调参工作表](references/tuning-worksheet.md)。本地内容可支持初步估算和实验设计；涉及具体 API、机型规格或版本差异时，仍需核对当前官方资料和本机实现。离线时明确尚未核对的事项。

## 确认模型与输入

读取当前 AGENTS.md、启动命令、生效配置、资产与日志，记录 Isaac Sim / Kit / PhysX 版本和实际后端。本教程针对 PhysX，不能直接证明 Newton 等后端的行为。

列出受驱动关节、被动/mimic/闭环关系、传动比和驱动类型。把当前资产与参考示例模型对比；关节数、闭环、控制器或碰撞几何不同，就重新估算。保留硬件规格、资产值、经验假设三个来源，不互相冒充。

检查实际命令路径：目标是否被控制器覆盖、力矩是否饱和、是否另有软件限速、材质及碰撞参数是否生效。避免仅修改 USD 中未被使用的 drive。

## 用工作表设计实验

在工作表中记录输入、单位、推导和不确定性，再选择改动。教程公式用于量级估计；静态力学计算不能替代运动机构的实际传动与负载映射。对复杂机构可结合雅可比/虚功或实测确认驱动力矩，不把示例中按关节数量累加的做法普遍化。

写属性前核对 USD schema、运行时 API 的单位与转换行为，检查封装层是否已转换，避免二次转换。将“推导使用的物理量”“接口接收值”“读回值”分列；读回一致后仍需实际运行验证。

参考笔记的增益估算按 force drive 推导；若实际使用 acceleration drive，改用对应模型，不直接复用其增益或单位。`maxForce` 对转动关节表示力矩限值，不因其名称含 force 就按接触点的牛顿值写入。

优先选择能够区分原因的局部实验，每轮改变一个因素或不可拆分的配置组合。公式重新计算后，应同时检查所有受影响的关联量。对改变物理模型的候选方案标明其数据依据，不仅凭画面更稳定就接受。

## 验证与交付

按工作表的实验记录比较基线和候选配置，保留复现初态、动作和固定仿真时长。质量达标后再评估耗时；没有真实 Isaac 环境时交付参数推导和实验步骤，明确未实测，不将配置校验当作夹持验证。

Real2Sim2Real 中遵守当前 AGENTS.md：仿真使用 `./app/python.sh`；机器人参数归 robot 后端，运行时求解参数归 simworld，任务控制归对应实现。保留 Job 生命周期与清理，不扩张通用 ABC；新增配置同步 Config、默认配置和适用示例。

输出实际模型与规格来源、估算假设和单位表、最小改动、前后实验结果及剩余限制。分别标注教程示例、项目推算和实测值。

关节发散或闭环问题参考 [稳定性 skill](../isaac-articulation-stability/SKILL.md)，碰撞质量参考 [碰撞 skill](../isaac-collision-debug/SKILL.md)，功能限制参考 [FAQ skill](../isaac-physics-faq/SKILL.md)，性能代价参考 [性能 skill](../isaac-physics-performance/SKILL.md)。按需读取。
